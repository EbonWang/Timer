01 / 产品介绍

只为「专注」而生的
全屏倒计时

极简倒计时把计时这件事做到极致：一个超大等宽数字舞台，一栏安静的工具条， 没有多余的信息干扰。它适合演讲计时、番茄专注、烘焙烹饪、运动间歇， 以及任何需要「一眼看清剩余时间」的场景。

项目采用 Vite + TypeScript + Tailwind CSS 构建，计时核心逻辑与界面解耦， 已配备单元测试，可直接部署为静态站点。

  • 目标时刻 · 快捷分钟，双模式设定
  • 基于结束时刻计算，精度无漂移
  • 全屏结束提醒，会话自动编号

02 / 核心功能

克制的功能，恰到好处

每项能力都围绕「看清时间、专注当下」设计，不堆砌、不喧宾夺主。

目标时间

选择未来的日期与时刻，按墙钟剩余秒数倒计时，跨天、跨时都精准。

快捷时长

输入分钟数即刻开始，无需翻日历，适合番茄钟、间歇训练等高频场景。

精准无漂移

以结束时刻为锚点计算剩余秒数，而非简单递减，长时间运行依然准确。

全屏提醒

时间到，舞台切换为警示红，弹层提醒可一键重置，进入下一轮。

多端适配

超大数字随视口弹性缩放，桌面与移动端皆满幅呈现，清晰可读。

会话管理

每轮自动编号并标注 LOCAL 会话，运行中随时重置，状态清晰。

03 / 使用步骤

三步，开始倒数

01

选择方式

在工具条切换「目标时间」或「快捷时长」两种设定模式。

02

设定时间

目标模式选择日期与时分；快捷模式直接输入分钟数。

03

开始倒计时

点击「开始倒计时」，舞台开始倒数，时间到即全屏提醒。
